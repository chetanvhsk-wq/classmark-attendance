Add your Gemini API key

  1. Get a key from Google AI Studio using the button below.
  2. Open the project’s .env file in a text editor and set GEMINI_API_KEY=your_key.
  3. Save the file, restart the local app with npm run dev, then tap Check server key.
  4. Paste your attendance table or choose your timetable photo, then review the result before applying.

The key stays in .env. Do not paste it into the webpage or commit the file.
